# Chaos Control

Chaos Control es un Network Task Manager para Windows orientado al monitoreo y control de red por proceso.

## Funciones principales

- Monitoreo de red por proceso.
- Tráfico de subida y descarga.
- Conteo de paquetes.
- Conexiones TCP/UDP, direcciones IP y puertos.
- Gráficas en tiempo real.
- Control y bloqueo de red.
- Reproductor de música integrado.

## Requisitos

- Windows 10 u 11 de 64 bits.
- Ejecución como administrador para las funciones avanzadas de red y firewall.

Versión académica preparada para feria universitaria.
